Privacy policy

Effective November 8, 2026.

This policy covers Hermes Personal, an independently operated desktop assistant integration for private, personally authorized use.

Google information accessed

When a user connects Gmail, the integration accesses the messages, attachments, headers, labels, draft content and other mailbox metadata needed for requested mail tasks. Basic Google account identity, such as the account's email address and profile information, identifies the connected account. Access depends on the scopes the user grants. Gmail authorization does not grant access to other Google services.

How information is used

Google information is used to perform the connected user's requested search, reading, drafting, sending and mail-organization tasks, and to provide related contextual assistance. The integration is not an autonomous public email service. Granting permission does not itself instruct the assistant to send a message or change mail.

Google user data is not sold, used for advertising or used to train generalized artificial intelligence or machine-learning models.

Processing and sharing

Local inference is the default. Requested message content and tool results are processed by the configured assistant. If a user explicitly configures and selects an external model or service for Google-data tasks, relevant context may be transmitted to that provider to fulfill the request. Such a provider should be used only with an appropriate data-processing configuration; Google data must not be used for generalized model training.

Access is limited to the connected user, the operator administering that user's integration and services explicitly configured to perform the requested function. Human access to Google data is limited to user-authorized assistance, security investigation, legal obligations or other cases permitted by Google's Limited Use requirements. There is no public mailbox-data sharing service.

Storage and retention

OAuth credentials and integration state are kept in private local runtime storage, outside this public website and its source repository. Local storage is subject to the computer's account-access controls. Requested excerpts and tool results may be retained in the assistant's local conversation history or other explicitly configured storage.

Locally retained data remains until the user or operator deletes it through the applicable local data controls. There is currently no automatic retention/deletion service. Messages in Gmail remain subject to the user's Google Account settings and any mail actions the user requests.

Revocation and deletion

A user can revoke the integration's access through Google Account third-party connections. Revocation stops future authorized API access. It does not automatically erase previously retained local conversations or exported files; those must be removed separately through the operator's local data controls.

For assistance removing local credentials or retained data, contact the operator using the contact method below. Do not post private data in a public issue.

Google API policy

Hermes Personal's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This information website

This static website uses no application forms, client-side scripts or analytics added by us. GitHub Pages hosts it and may process ordinary request information under the GitHub Privacy Statement. The site does not collect mailbox data or OAuth credentials.

Contact and updates

The operator is the owner of this information repository. Contact the operator for support or privacy questions through the repository's public issues, without including sensitive information. Changes to data practices will be reflected on this page with an updated effective date.
