# Hermes Personal information pages

Public app-information and privacy pages for a private desktop assistant integration.

- [About](https://ttager16.github.io/hermes-personal-info/)
- [Privacy policy](https://ttager16.github.io/hermes-personal-info/privacy.html)

This repository contains only static public information. The assistant implementation, credentials, configuration and runtime data are maintained separately.

Published from the root of the `main` branch using GitHub Pages. No build dependencies, JavaScript or application backend.

For support or privacy questions, contact the repository owner through [Issues](https://github.com/ttager16/hermes-personal-info/issues). Issues are public; do not include private messages, credentials or files.
